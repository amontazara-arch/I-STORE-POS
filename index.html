1 الطريقة الأولى: فتح تطبيق واتساب (WhatsApp Web / App)

كيف تعمل؟ عند اختيار هذه الطريقة:

  • يقوم النظام فوراً بتوليد صورة عالية الدقة للوصل (A4 أو حراري).
  • يتم تحميل الصورة تلقائياً إلى جهازك أو هاتف المحل وتنبيهك.
  • يتم فتح محادثة الزبون على تطبيق واتساب مباشرة مع رسالة مفصلة جاهزة تحتوي على المجموع والتفاصيل، وتقوم فقط بإرفاق الصورة المحفوظة وإرسالها!
  • الميزة: مجانية 100%، لا تحتاج لأي اشتراك أو خدمات خارجية، وتعمل على أي هاتف أو كمبيوتر.

2 الطريقة الثانية: الإرسال التلقائي عبر بوابة الـ API (صامت خلف الكواليس)

كيف تعمل؟

  • يتم إرسال صورة الوصل مباشرة إلى رقم واتساب الزبون بضغطة زر واحدة دون فتح أي برامج.
  • يتطلب ذلك ربط بوابة WhatsApp API (مثل خدمة UltraMsg أو Whapi أو خادم WhatsApp Gateway خاص بك).
  • الخطوات: اشترك في مزود الخدمة واحصل على (معرف الجلسة Instance ID) و (رمز الـ API Token)، ثم ضعهما في حقول الإعدادات واضغط "حفظ".
